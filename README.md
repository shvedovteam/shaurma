# Shaurma Gumry

Prototype and implementation of a direct-ordering website for a local food business in Gyumri.

## Design source

Figma: https://www.figma.com/design/X2Os31gFTJ8oVP3iToHT8b

Current concept direction: Sweetgreen-inspired food-first visual language combined with East West-style ordering UX.

## Current design scope

- Desktop: Home + Menu
- Mobile: Home + Menu
- Fast add-to-cart interaction concept
- Delivery / pickup flow concept
- Fresh bread / lavash brand section

Design exports and handoff notes are stored in `/design`.
